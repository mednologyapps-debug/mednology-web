Un pedido pagado, una sola factura

Cuando la tienda confirma un pago, el sistema de facturación necesita reconocer el pedido aunque reciba el aviso dos veces. Definimos un identificador común, cómo registrar la respuesta y qué debe ver operaciones si la factura queda pendiente.

Qué preparar para una cotización

Indica qué plataformas usas, qué datos deben viajar en cada dirección y con qué frecuencia. Si existe documentación de la API o un ambiente de pruebas, podemos revisar antes las limitaciones del intercambio.
